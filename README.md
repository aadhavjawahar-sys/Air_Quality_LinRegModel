# Air_Quality_LinRegModel

## Introduction

The following repository follows an **attempt** at a multivariable linear regression model on an air quality [dataset](https://archive.ics.uci.edu/dataset/360/air+quality). However, after creating the model, I realized the MSE was too high, leaving me to think that the features I chose may not be influential for the selected target. 

***

## Future work

Due to the late realization of a disconnect between the features and target, I have resorted to temporarily *scrapping*, probably permanently, scrapping the project. Though, I have kept the repository as it shows the correct way to create a multi-variable linear regression model.
